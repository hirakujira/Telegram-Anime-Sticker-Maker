# Telegram 本機影片貼圖工具

## 啟動

已安裝 Python 3.10 以上及 ffmpeg、ffprobe（需要 `libvpx-vp9` 與 `libx264` 編碼器）即可使用：

```sh
./run.sh
```

首次啟動會建立 `.venv` 並安裝 Python 套件。開啟 [本機網頁](http://127.0.0.1:8765)。按 `Ctrl+C` 停止；再次執行同一指令即可重開。需要其他連接埠或影片資料夾時：

```sh
./run.sh --port 8766 --directory '/完整路徑/影片資料夾'
```

## 製作流程

1. 將影片放進資料夾第一層，按「重新掃描」，再選擇影片。支援 MP4、MKV、MOV、WEBM、AVI、M4V、MPEG、MPG、MTS、M2TS。掃描不會遍歷子資料夾。
2. 影片可立即播放。第一次選取會在背景讀取原始影格時間索引，長影片可能需要數十秒；之後可使用快取。瀏覽器不支援來源編碼時，會自動產生相容的 MP4 預覽，也可按「轉換播放格式」。
3. 拖曳起點／終點滑桿，或輸入秒數。也可播放至想要的位置，按「使用播放位置」。將起點移到原範圍之後時，工具會一起移動終點。
4. 索引完成後，可直接輸入影格編號、按 `−`／`＋` 逐格微調，或查看起點／終點的原片靜態影格。**影格從 1 開始，包含起點與終點。** 結束秒數是終點影格播放完的位置。
5. 選擇正方形或原始比例。正方形以原片短邊為邊長，可拖曳取景框、輸入裁切像素或使用靠左／置中／靠右。橫向影片預設靠右；直向影片提供上下位置。裁切像素以旋轉及像素比例校正後的原片尺寸計算。聚焦裁切框後，也可用方向鍵微調，按住 Shift 一次移動 10 px。
6. 設定播放倍率，預設 `1×`。選取片段按該倍率播放後不可超過 3 秒；超過時會顯示所需最低倍率，不會截掉內容。
7. 按「製作貼圖」，完成後預覽、下載 `.webm`。也可直接從 `stickers/` 取得成品。每次製作使用不同檔名。

## 格式與檔案

- 成品使用 VP9／WEBM，30 FPS、無音軌。正方形為 512×512，原始比例為長邊 512 px。為配合輸出幀率，顯示時長會向上取整到 1/30 秒；最多仍為 3 秒。
- 自動降低編碼品質及必要時使用兩階段壓縮，容量採較保守的 **256,000 bytes** 上限。壓縮後會驗證成品；多次壓縮仍不符合時，請縮短片段重試。
- 輸出由原片製作，保留背景。相容 MP4 只用於瀏覽器預覽；精準逐格畫面取自原片。
- `.cache/` 存放影格時間索引、相容預覽及最多 128 張單格 PNG，沒有整部影片的 PNG 序列。程式停止後可刪除 `.cache/` 釋放空間；再次使用會重新建立。
- 所有工作留在本機，服務僅監聽 `127.0.0.1`。不自動上傳 Telegram。
- 來源檔案變更後需重新掃描。程式重新啟動後，工作狀態會清除，已完成的貼圖仍保留在 `stickers/`。

下載後，開啟 [Telegram @Stickers](https://t.me/Stickers)，使用 `/newvideo` 建立影片貼圖包，再以檔案方式傳送 `.webm`。詳細要求參考 [Telegram 官方規格](https://core.telegram.org/stickers#video-stickers)。

## 驗證

```sh
.venv/bin/python -m unittest discover -s tests -p test_media.py -v
```

測試會在暫存資料夾產生合成影片，檢查原始影格索引、裁切、旋轉、可變幀率、速度、時長、容量重試及 HTTP 播放／下載，不會更動你的影片。
